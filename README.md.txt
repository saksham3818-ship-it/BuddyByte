# 🎓 AI Student Support Bot

An **AI-powered Student Support Chatbot** that helps students with academic queries using cutting-edge AI technology.

## 📋 Quick Links
- **🔗 GitHub Repository**: https://github.com/saksham3818-ship-it/AI-STUDENT-SUPPORT
- **🌐 Live Demo**: http://localhost:8501 (when running locally)
- **👤 Developer**: [@saksham3818-ship-it](https://github.com/saksham3818-ship-it)

## 📖 Project Description
This project is an AI-powered Student Support Chatbot developed using Python, Streamlit, and the Groq API. It helps students by answering academic queries about:
- 💻 Coding & Programming
- 📊 Data Structures & Algorithms (DSA)
- 🗄️ Database Management Systems (DBMS)
- 🖥️ Operating Systems
- 🌐 Computer Networks
- 🤖 Artificial Intelligence & Machine Learning
- 💼 Placements & Career Guidance
- 📝 Assignments & Projects

## 🎨 Features
- ✨ Clean, light blue interface with black headings
- 📋 Collapsible menu for easy navigation
- 💬 Real-time AI chat powered by Groq API
- 🚀 Fast and responsive chatbot
- 📊 Dashboard with learning metrics
- 📚 Study resources section
- 🎯 Placement preparation tools
- 🧠 Interactive quizzes

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saksham3818-ship-it/AI-STUDENT-SUPPORT.git
   cd AI-STUDENT-SUPPORT
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Create `.env` file**:
   ```
   GROQ_API_KEY=your_groq_api_key_here
   ```

4. **Run the application**:
   ```bash
   streamlit run app.py
   ```

5. **Open in browser**:
   - Local: http://localhost:8501
